# Work on Chandra for Windows

This repository preserves Const-me/Whisper's history while adding Chandra OCR 2 inference, numerical validation and endpoint routing for Windows Intel GPUs. Read [Readme.md](Readme.md), [the design](docs/design.md) and [the work record](docs/work-record.md) before resuming. Keep the original MPL-2.0 license and upstream attribution; model weights have their own license.

The October 15 backend decision makes maintained llama.cpp engines the current candidates; follow [the engine trial](docs/sycl-engine-trial.md). The repaired SYCL baseline passed complete source checks at C1, C2 and C4; C4 was best among those finite observations at 0.0437940 original-endpoint pages/s. A fused vision-attention candidate passed small CPU-reference controls and two complete C4 cohorts at 0.0667348 and 0.0677441 pages/s, with all 85 warmup/measured responses passing source checks. Each baseline has one observation; repeated paired comparisons and accumulated numerical-drift checks remain pending before promotion, with no numerical equivalence or global throughput ceiling established. Vulkan remains selected at four concurrent requests. Backend choice is authorized, including AdaptiveCpp, XPU or OpenVINO when evidence supports a separate candidate. Preserve the original SYCL startup failures and DirectCompute implementation as historical references; their progression holds do not govern a new engine. Bounded complete-page runs and provisional timings are allowed to learn about a candidate before promotion.

Those two vision cohorts used one-logical-CPU Jobs. A subsequent [four-logical-CPU affinity observation](benchmarks/evidence/sycl-vision-affinity-2026-10-16.json) reached 0.0742634 original-endpoint pages/s at C4, 9.62% above the same-duration 720-second reference, with all 60 source checks passing and clean closure. This single affinity observation does not establish a repeatable gain, numerical equivalence or a throughput ceiling; Vulkan remains selected.

Correctness precedes performance. Pin the model revision, processor, runtime and input pixels; compare numerical outputs and complete OCR before promoting a faster implementation. A kernel probe is evidence for that kernel, not proof that the full model works. Record failures and missing measurements as such. Never silently fall back to a CPU, change precision, trim image dimensions or output allowance, or substitute a different checkpoint.
