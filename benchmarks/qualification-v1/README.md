# Independent synthetic regression set

These two newly composed pages freeze an independent synthetic regression set before any baseline or optimized candidate inference. `routes.png` uses two separate prose columns, distinct headings and a short equation; its expected reading order completes the western column before the eastern column. `ledger.png` places signed and decimal quantities in a four-station table, followed by a footnote, an audit note and a terminal sentinel. Neither page is a resized variant of the development template. All content is fictional; this set supports bounded regressions and establishes no real-world general accuracy claim.

[manifest.json](manifest.json) freezes structured expected content, exact table cells, reading order, sentinels, draw regions, PNG and decoded RGB pixel hashes, generator identity and the DejaVu Sans font hash. Both 1000 by 1200 RGB PNGs were visually inspected for legible text, complete table cells, separated columns and unclipped terminal markers. Regeneration uses the project's benchmark environment with `python benchmarks/qualification-v1/generate.py --font /path/to/DejaVuSans.ttf`; the generator refuses to replace an existing manifest. The source font license is retained in [DejaVu-LICENSE.txt](../DejaVu-LICENSE.txt).

The planned completion budget is approximately 400–650 tokens per page including layout markup. This is a planning estimate, not a measured output length or a token cap. Retain the qualified model, processor, prompt, precision, request dimensions and ordinary 12,384-token output allowance; measure actual complete output length before scheduling repeated timing runs. Pin the manifest hash and the actual request's decoded input pixel identity in each run; preprocessing changes require explicit evidence rather than silent resizing.

[validate.py](validate.py) runs offline without a model. `python benchmarks/qualification-v1/validate.py routes candidate.json --reference baseline.json` accepts saved endpoint-run JSON or ordinary completion JSON. Both outputs must independently satisfy the frozen expected content: omitted or changed text, duplicated blocks, wrong reading order, changed signed values or decimal precision, displaced table associations, missing terminal sentinel, non-stop finish, stream errors and missing or exhausted output usage fail the gate. Only whitespace, explicit math delimiters and the Unicode minus glyph are normalized; other representational differences remain visible failures requiring review rather than post-hoc edits to expectations.

Geometry is recorded separately from content acceptance. Generated drawing regions locate source text but are not OCR box ground truth. The comparator associates observed layout blocks by unique normalized content and reports raw boxes, labels and ambiguous or missing associations. Supply `--geometry-space` only when the two outputs' coordinate convention is established; it then reports coordinate differences without inventing a tolerance or converting an unknown convention. Geometry observations alone cannot promote a candidate.
