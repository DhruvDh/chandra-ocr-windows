# Experimental bounded SYCL decode graphs

[candidate.patch](candidate.patch) and [extension.patch](extension.patch) are the exact two retained graph patches against llama.cpp [d81235049384534c167caea52b85a694f6103d14](https://github.com/ggml-org/llama.cpp/tree/d81235049384534c167caea52b85a694f6103d14) (b11429), applied in that order with the existing [vision attention dependency](../vision-sdpa-d812350/README.md). Together they change five graph source files; the vision dependency changes two other files. The closed build produced a 65,091,072-byte `ggml-sycl.dll`, SHA256 `4e4445190ab5b7686a0990c11aa8faf8f0c27bbf2b9f445430193b0aaa446234`. This directory publishes source and reproducibility records for that experimental leaf. It supplies no sustained-throughput result or normal-service deployment acceptance.

The upstream patch's raw selector `GGML_SYCL_DECODE_GRAPH` defaults to `0`. Its raw mode `1` retains the original four-sequence BF16 attention experiment; raw mode `2` selects exactly six Q8 sequences and raw mode `3` selects exactly five Q8 sequences. The default-off public `sycl_decode_graph` boolean exposes only raw mode 3 in the pinned C5/b256 profile; raw modes 1 and 2 are not supported public configurations. The ordinary upstream `GGML_SYCL_ENABLE_GRAPH` must remain `0`; enabling both graph selectors is refused. The observed original-page episode uses mode 3 with Q8 text and K/V, the unchanged BF16/F32 projector, fused vision, batch/microbatch 256, five nonunified 16,384-token slots and the normal 12,384-token output allowance. Mode 2 is a compiled capability without a Q8 C6 runtime qualification in this record. Profile selection never infers a smaller width: mode 2 draining to five sequences executes eagerly.

Capture is bounded to the checked native decode topology: 24 GDN operations, eight attention operations and 24 CONCAT operations; the Q8 profiles additionally require 16 rotations at each of widths 64 and 256. Their attention route requires Intel DG2/ACM-G10, one query per sequence, head dimension 256, four KV heads, Q8 K/V, F32 query/output and an F16 mask, with actual VEC-kernel selection. Native Q8 MMVQ/DMMV, SET_ROWS and FWHT dimensions are checked. Prefill and unsupported shapes remain eager. There must be one visible SYCL device, asynchronous memory operations and the limited-graph capability. `GGML_SYCL_DEBUG`, `GGML_SYCL_DEV_DEBUG`, `GGML_SYCL_MEMTRACE`, `GGML_SYCL_SPARSE_FA`, `GGML_SYCL_MKL_FA_DIAG` and `GGML_SYCL_MKL_FA_DEBUG` must be zero or absent. Turning on backend diagnostic execution modes can make the graph ineligible; ordinary INFO logging is sufficient for the retained graph markers.

One serial backend context owns one cached graph. Its signature includes profile identity, graph topology/use counts, tensor/source identities, addresses, shapes, strides, operation parameters, dispatch settings and storage/scratch epochs. The first eligible step warms the native path; capture uses warmed scratch only. Descriptor, storage or scratch changes discard the cached graph with a queue wait, including padded-KV growth and slot turnover. Unsupported work executes eagerly before submission. A capture or submission failure aborts without retrying that state-mutating invocation. Preserve one submitting host thread, ordered queue use, storage lifetime and owned process retirement; this source is not an arbitrary-shape or concurrent-submitter graph cache.

## Apply and build in a private project directory

Use a fresh private source checkout and a separately owned build. [provenance.json](provenance.json) binds the exact upstream/archive, both patch files, intermediate and final source identities, actual build evidence and runtime leaf. Its pinned dependency on [the vision provenance](../vision-sdpa-d812350/provenance.json) supplies the shared Intel kit URL/hash, selected SDK components, extracted SDK layout, VS tool identities, child-local environment and base CMake options. Retain that dependency byte-for-byte. The observed SDK is Intel oneAPI 2026.1.1.32, using IntelLLVM 2026.1.1, oneDNN 3.11.4, MKL 2026.1 and TBB 2023.1; VS 2022 x64 uses MSVC 14.44.35207 and Windows SDK 10.0.26100.0. The private SDK archive and all licenses remain outside this source package. The dependency documents archive-data extraction with no installer hooks or global configuration changes; private extraction and ownership helpers are not redistributed.

Define `$Source`, `$Build`, `$Sdk`, `$PatchDir` and `$VisionPatchDir` as operator-chosen absolute paths, with the latter two naming these graph files and the sibling vision package. Define `$CMake`, `$Ninja` and `$Cl` as authenticated tool paths and initialize the child-local VS/SDK environment from the pinned dependency before configuring. Preserve `CXXFLAGS=-fsycl-max-parallel-link-jobs=1` and CMake's C++ exception defaults; replacing `CMAKE_CXX_FLAGS` loses required defaults. The following is an application/configuration recipe, not a resource supervisor or permission to execute a model. Check each native command's exit code before proceeding.

```powershell
git -C $Source checkout --detach d81235049384534c167caea52b85a694f6103d14
if ($LASTEXITCODE -ne 0) { throw "Pinned source checkout failed" }
foreach ($patch in @("$VisionPatchDir/candidate.patch", "$PatchDir/candidate.patch", "$PatchDir/extension.patch")) {
    git -C $Source apply --check $patch
    if ($LASTEXITCODE -ne 0) { throw "Patch check failed" }
    git -C $Source apply $patch
    if ($LASTEXITCODE -ne 0) { throw "Patch application failed" }
}

$v = Get-Content -Raw "$VisionPatchDir/provenance.json" | ConvertFrom-Json
$p = Get-Content -Raw "$PatchDir/provenance.json" | ConvertFrom-Json
$flags = @($v.build.cmake_cache.PSObject.Properties | ForEach-Object { "-D$($_.Name)=$($_.Value)" })
$flags += @($p.build.cmake_cache_overrides.PSObject.Properties | ForEach-Object { "-D$($_.Name)=$($_.Value)" })
$paths = @($v.build.sdk_cmake_paths.PSObject.Properties | ForEach-Object { "-D$($_.Name)=$Sdk/$($_.Value)" })
& $CMake -S $Source -B $Build -G Ninja @flags @paths "-DCMAKE_C_COMPILER=$Cl" "-DCMAKE_MAKE_PROGRAM=$Ninja"
if ($LASTEXITCODE -ne 0) { throw "Graph leaf configuration failed" }
& $Ninja -C $Build -j1 ggml-sycl
if ($LASTEXITCODE -ne 0) { throw "Graph leaf build failed" }
```

## Enable and assess the finite experiment

The adapter scrubs inherited environment overrides. The observed isolated service source deliberately supplied `GGML_SYCL_ENABLE_GRAPH="0"`, `GGML_SYCL_DECODE_GRAPH="3"` and the two existing fused-vision flags in the owned engine child, with a separately authenticated graph runtime inventory. It retained the Level Zero device binding, Sysman exclusions, private persistent compiler cache, four logical CPUs in both Jobs, llama/OMP/MKL thread counts one, 10.5/10.75 GiB process/Job caps, strict 4 GiB physical/system-commit floors and explicit admission forecasts. The actual default-off public `sycl_decode_graph` selector and its exact C5/b256 identity, admission and resource guards are documented in [the adapter contract](../../README.md); normal-service selection still requires its own reviewed configuration and operational evidence. The isolated graph forecast allowance is provisional; graph finalization, driver/JIT allocation, residency and incremental physical use are not bounded by the completed build or page results.

The retained Q3 page episode added `--log-verbosity 4` as the first engine option, before device selectors initialize SYCL, and used the separately reviewed bounded stderr-forwarding observer. A late verbosity option had hidden one-time settings in Q2; that failed assessment remains preserved. Complete INFO settings and capture/replay/invalidation markers are necessary evidence. The ordinary worker's bounded stderr tail alone does not establish complete startup history. These logging/observer changes are qualification instrumentation outside the upstream patches; no private service packet or raw run is shipped here.

Q3 completed two sequential five-request original-page cohorts across four distinct synthetic cases, with native-0 repeated in each. Each cohort used all five slots, captured/replayed at padded KV lengths 3,840, 4,096 and 4,352, and completed before slot reuse in the next cohort. The saved assessment reports six captures, six first-replay markers, six invalidations, ten natural complete responses and ten passing unchanged source checks. Its strict single-eager-reference verdict is false: one scanned-0 table edge changes from 925 to 926. All ten complete content/full-usage tuples exactly belong to nine historical eager variants frozen before the graph comparison; the exceptional page equals the original eager measure-0030 variant. Keep both verdicts, the finite family and its unmatched streaming/scheduling scope. The assessment retains `qualified:false` and no general numerical qualification. Output membership and source agreement do not establish equal states/logits, equal output distributions, general OCR accuracy or a graph speedup.

Q3 also records affirmative inner/outer retirement with no fault, zero active Job processes, closed resources and all held inputs released; deliberate parent-requested engine status 3235774465 is retained. This finite page/ownership result supplies neither sustained throughput nor normal-service cancellation, CLI, 300-second idle or deployment acceptance.
