# Explicit-mask text SDPA candidate

This opt-in process-local candidate leaves the hybrid loader unchanged and replaces only Qwen3.5's eager full-text attention function inside a restoring context. Keeping text configuration eager is essential: upstream constructs its complete additive causal mask, including padding and packed-sequence restrictions, instead of invoking SDPA's mask-elision optimization. The candidate refuses a missing mask, mask slicing, training, attention-weight requests, changed source, changed device or changed precision. Boolean conversion accepts only zero and negative infinity or dtype-minimum masking entries; arbitrary additive biases fail rather than disappearing. The additive variant preserves floating masks exactly. Math SDPA is excluded explicitly. Manual KV repetition retains the eager GQA layout.

Queries and keys arrive after upstream Q/K normalization and rotary embedding and keys/values arrive after upstream cache update. The candidate does not derive causality from multimodal rotary coordinates: those can differ from chronological cache positions. Upstream's four-plane position convention separates the text position plane from temporal/height/width rotary planes. The existing cached exporter intentionally uses its preserved three-plane MRoPE plus rope delta; the candidate changes none of these coordinates. Explicit masks carry causality and SDPA always receives is_causal=False, avoiding the incorrect upper-left single-query alignment. A null mask is an error even if all prior tokens would be visible.

Run only after the coordinator grants an exclusive GPU lease and unloads the serving model. Obtain the graph hash by hashing the installed modeling_qwen3_5.py directly on Windows; redirected SSH text is not a reliable byte hash because line endings and encoding can change. Use the existing frozen model, image, prompt and CPU reference response arguments; supply a new private output directory for each run. The shared exporter retains exact processed inputs, full-vocabulary rows, cache receipts, model/source/input hashes and greedy token IDs. Its runtime label remains hybrid because that is the loader setting; attention-candidate.json is mandatory to identify the patched graph. Do not classify candidate exports from runtime.attention alone.

Example argument shape (replace placeholders with already frozen local inputs): `python experiments/xpu-hillclimb/run_attention_candidate.py --graph-sha256 HASH --mask-kind boolean -- --model MODEL --image IMAGE --prompt PROMPT --response RESPONSE --output FRESH_DIRECTORY --device xpu --attention hybrid --all-teacher`. Repeat with `--steps 8 --check-cache-equivalence` and then cache lengths 1, 32, 128 and the full response; the starting 801-token prefill is preserved. Compare each export against the matched hybrid and CPU BF16/FP32 exports using verification/compare_exports.py. Capture real trained failing-layer Q/K/V and masks through the fixture callback, which runs after rotary/cache update and before KV repetition; retain tensors only in private experiment output. Replay each trained fixture against eager and strict explicit SDPA to locate any divergence.

Before timing, require finite logits and recurrent/cache tensors, exact conditioning identity, all teacher rows, cached/full error and greedy choices comparable to qualified hybrid (the earlier maximum 5.875 failure is unacceptable), and complete tiny/small/representative OCR with checkpoint EOS plus im_end termination. Use the existing exporter's independent greedy path with the unchanged production output allowance, then verification/compare_ocr.py against retained CPU/qualified-hybrid outputs and benchmark content gates. Bounding-box digit differences require geometry inspection. Run repeated pages in one isolated model process and verify no cache/state leaks before any serving proposal. Endpoint cancellation and admission checks remain prerequisites for deployment; this experiment does not deploy.

The boolean candidate deliberately validates mask values synchronously on every attention call. Its cost belongs in measured performance and may erase a fused-attention improvement. Avoid removing that check until a separately guarded mask producer is proved equivalent. Preserve masked/additive failures and missing measurements. No full-model acceptance is implied by successful import, compilation or the earlier synthetic operator probe.

The first leased eight-step trained full-model run completed under a 180-second owned-process-tree deadline in 27.454 seconds. Its predeclared cache gate required finite tensors, identical inputs, the same cached/full greedy token and errors no greater than the qualified hybrid's maximum 0.0625 and RMS 0.0096618524. It failed: maximum 0.125 and RMS 0.0126220677, despite finite tensors and the same greedy token. All-teacher and complete OCR were therefore not launched. The candidate remains unqualified and serving remains hybrid. The deadline helper retains logs and partial artifacts and records completed, failed and deadline-exceeded distinctly. It must run inside the authenticated run_channel Windows Job Object, which owns cleanup after interruption or SSH loss; the helper alone does not provide that ownership.

Subsequent CPU-only calibration did not revise that failed gate. The matched CPU BF16 SDPA cached/full result has maximum 0.125 and RMS 0.0126029616, suggesting an SDPA arithmetic boundary worth independent review. Candidate versus hybrid had nine of nine greedy agreements, maximum logit difference 0.375 and maximum KL 0.0126586; its top ten reference logits differed by up to three BF16 spacing units and up to 16.55 percent of vocabulary entries differed by more than 0.0625 in a row. The changes are not confined to one top-logit ULP. Against the matched CPU FP32 full-forward oracle at the same nine positions, all greedy choices agreed, maximum logit difference was 0.600506 and maximum KL 0.0215150. This nine-row calibration does not replace all-teacher, long cached generation or OCR gates.

Nine actual first-full-attention-layer fixtures cover 801/801 prefill and 1/802 through 1/809 cached shapes. CPU math SDPA with boolean and additive masks was bit-identical on all nine. Against independent FP32 eager softmax/matmul, CPU BF16 masked SDPA had prefill maximum error 0.0154519 and RMS 0.0006787; the cached cases had maximum errors 0.0038521 through 0.0077028 and RMS approximately 0.000604 through 0.000692. BF16 eager errors were larger. No XPU trained-fixture replay occurred after release of the GPU lease. The retained private receipts and tensor hashes preserve this distinction. The wrapper now bounds captures to batch one, at most sixteen shapes, 64 MiB per capture and 128 MiB aggregate; the first nine captures totaled approximately 37 MiB.

The final CPU-only review compared qualified hybrid and candidate against the same matched CPU FP32 vocabulary rows at positions 800 through 808, checking processed tensor identity, prefix and conditioned targets. Model revision, graph hash and runtime parity are explicit in the original exports; this comparison uses CPU full teacher rows against both Intel cached paths, rather than claiming an independently measured CPU cached trajectory. Both Intel paths matched all nine reference argmax choices. Hybrid versus CPU had maximum absolute error 0.427341, maximum RMS 0.0768230, maximum KL 0.00237702 and mean KL 0.000422151. Candidate versus CPU had maximum absolute error 0.600506, maximum RMS 0.0824114, maximum KL 0.0215150 and mean KL 0.00373498. The candidate's mean and maximum KL were roughly nine times the hybrid values. At positions 805, 806 and 808, CPU-to-hybrid KL was respectively 0.00237702, 0.00142159 and 0.000000667165; CPU-to-candidate KL was 0.0116527, 0.0215150 and 0.000447026. All listed KL values use CPU FP32 as the reference direction.

This early distribution regression is an additional reason to set this implementation aside. No further attention GPU trial or promotion is scheduled: the expected modest attention speed benefit does not justify prioritizing it over the measured recurrent dispatch bottleneck. The original failed cache gate remains unchanged, CPU operator closeness remains mechanism evidence only, and no speculative permissive future thresholds are frozen. A future attention implementation would require a separately approved, reference-calibrated protocol and a new GPU lease. Public source contains parameterized commands and synthetic measurements; raw responses, tensors, receipts and actual host paths remain in private evidence. No serving configuration was changed or commit made by this experimental worker.
